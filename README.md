# EQ5D-Mapping-Calculator

This is a user-friendly calculator for mapping between EQ-5D-5L and 3L.

**Online URL**: [https://yourenchou.shinyapps.io/Mapping_Calculator/](https://yourenchou.shinyapps.io/UK_EQ-5D_Mapping_Tool/)

References: EEPRU paper - Hernández Alava, M., Pudney, S. & Wailoo, A. Estimating the Relationship Between EQ-5D-5L and EQ-5D-3L: Results from a UK Population Study. PharmacoEconomics (2022). https://doi.org/10.1007/s40273-022-01218-7.
